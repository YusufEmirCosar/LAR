const std::optional< GeoCoordinateRadians > & groundOrigin = std::nullopt )
staticnodiscardnoexcept

Projects all available target/LAR data around the aircraft origin.

East maps to +X, north maps to -Z, and radii are converted from metres using the fixed aircraft-derived scale. Ground bounds expand for content and altitude; an optional persistent origin fixes grid phase to Earth.

The operation follows the contract of the owning type and preserves its documented invariants.

Parameters
[in]sceneScene supplied to the operation.
[in]metersPerSceneUnitMeters Per Scene Unit supplied to the operation.
[in]groundOriginGround Origin supplied to the operation.
Returns
The value produced by the operation.
