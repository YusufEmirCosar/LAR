Detailed Description

Draws regular IR/IZ zones from compact parameters and static LOD.

setZones() proves fixed topology and float-coordinate error against the 0.65-pixel error contract. Pole-clipped, extreme-zoom, or numerically sensitive zones are rejected and remain on the revisioned CPU mesh path.
