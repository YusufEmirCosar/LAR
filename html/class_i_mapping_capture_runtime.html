Detailed Description

Every structurally valid command returns an accepted dispatch with a unique non-zero request ID.

Operational success or failure is reported through the matching typed result/failure signal. Invalid arguments and post-shutdown commands are rejected immediately and produce no operational completion. Segregated command port for mapping, access policy, and online capture.
