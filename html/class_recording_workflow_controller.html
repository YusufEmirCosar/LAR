bool RecordingWorkflowController::prepareToStopOnline ( )

Confirms and prepares stopping online capture.

An empty recording is discarded without prompting. A non-empty recording requires confirmation before it is discarded and the online source is stopped.

Returns
True when stopping is accepted or queued; false when the user cancels or the application rejects the request.
