bool MappedPacketDecoder::decode ( const QByteArray & packet,
Plane * plane,
Target * target,
QBitArray * availableFields,
QString * error = nullptr ) const
inline

Compatibility adapter for legacy callers that consume separate LAR outputs.

New runtime code uses the atomic DecodedState overload above. Keeping this non-virtual adapter avoids forcing independent mapping clients to migrate in lockstep while still making the port contract atomic.

The operation observes the current object state without modifying it.

Parameters

[in]planePlane state supplied by the caller.

[in]availableFieldsBitset identifying which state fields contain valid values.

Returns
True when the operation succeeds; false otherwise.
