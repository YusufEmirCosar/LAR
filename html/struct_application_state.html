Detailed Description

Authoritative workflow state owned by ApplicationFacade.

Presentation data (the latest Plane/Target and formatted metrics) remains in ApplicationViewModel. Lifecycle and command-eligibility facts live here so they cannot drift across unrelated facade booleans.
