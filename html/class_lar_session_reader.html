Detailed Description

Validates a session once, checkpoints it sparsely, and decodes on demand.

The reader deliberately has no record-count policy limit. A checkpoint is retained for every 4,096 records and only one page of record locations is cached, preventing an attacker-controlled record count from creating a full per-record memory index. Like QFile, random-access methods are confined to the reader's owning thread.
